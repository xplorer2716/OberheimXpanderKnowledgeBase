# Contributing

Thanks for considering a contribution to the Oberheim Xpander Knowledge Base.

## Ways to contribute

- **New reference material**: manuals, service bulletins, datasheets, schematics,
  or photos relevant to the Oberheim Xpander or Matrix-12.
- **OCR corrections**: fixes to text produced by the OCR pipeline, especially
  numeric values, ranges, and units, which are the easiest to get subtly wrong.
- **Tooling improvements**: fixes or enhancements to the scripts in [`ocr/`](ocr/).

## Before submitting

- Only submit documents you have the right to redistribute (public domain,
  your own scans of material you own, or material you have permission to
  share). Do not upload copyrighted third-party material without a clear
  right to do so.
- Keep file names consistent with the existing convention in the target
  folder (e.g. `Manufacturer-DocumentType.pdf`).
- If correcting OCR text, note which page(s) and what changed in your pull
  request description, especially for numeric values.

## How to submit

1. Fork the repository and create a branch for your change.
2. Make your change, keeping unrelated changes out of the same commit.
3. Open a pull request describing what you added or changed and why.

## Reporting issues

If you spot an error in a manual transcription, a broken script, or missing
documentation, please open an issue describing the problem and, if possible,
the page/file affected.
